# RedAlertSim

红警风格 3D 网页 RTS，基于用户上传的 RedAlert3D Command v1.0.0 Full 完整工程。

## GitHub Pages

目标网址：https://clredfield.github.io/RedAlertSim/

完整工程导入后，在仓库 **Settings → Pages** 中选择 **Deploy from a branch → main → / (root) → Save**。

联机使用游戏内 **公共 MQTT 中转** 模式，房主创建房间后发送完整邀请；GitHub Pages 只托管网页，不运行游戏服务器。房主须保持页面开启，公共测试节点不保证稳定性。

本仓库正在初始化；在游戏文件导入和 Pages 首次发布完成之前，上述网址尚不能作为已上线入口。
