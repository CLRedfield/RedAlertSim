RedAlert3D Command Edition 1.0.0

1. 完整解压，双击 PLAY.html。无需 npm 或素材下载。
2. 公网玩：联机大厅 -> 公共 MQTT 中转 -> 创建房间 -> 复制 RA1. 完整邀请。
   朋友打开同一版本，粘贴邀请 -> 加入 -> 准备 -> 房主开始。
   不需要自己搭服务器，默认用 EMQX 公共测试 broker。
3. 私密房间默认开启。不要只发送界面六位房间码，公网需要完整长邀请。
4. 房主必须保持网页和电脑运行。关闭/刷新房主页面会结束房间，无主机迁移。
5. 默认节点失败可以换候选重新创建。公共免费节点不保证稳定和中国各网络可达。
6. 同一局域网：房主运行 START_LAN.bat，朋友打开邀请链接。
   房主首次可能下载 Node，未将 Windows Node 二进制内置到压缩包。
7. 新内容：六个合作行动、延迟观战、检查点录像、多槽自动存档、科技路线、模型细节。
8. 新存档在浏览器本地。重要进度请导出 JSON 文件保存。
9. 详细测试边界、操作手册、升级清单在 docs 文件夹。真实公共网络和实体Windows未验收。

这是本项目1.0.0完整运行与源码包，不是商业原版所有规则、美术、战役的完整复刻。
