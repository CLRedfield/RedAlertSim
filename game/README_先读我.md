# RedAlert3D · Command Edition 1.0.0

这是基于 v0.6.0 完整包继续开发的自包含三维网页 RTS。v0.8 的合作、观战和回放内容已经合并进此 v1.0 交付，不需要安装中间版本。

**直接开始：完整解压，然后双击 `PLAY.html`。** Windows 也可运行 `START_SINGLE_PLAYER.bat` 或 `START_ONLINE.bat`。网页、模型、界面和生成音效均在本地，不使用素材 CDN。

## 和朋友在线玩，不用自行搭服务器

双方打开同一份 1.0.0 网页。进入 **联机大厅**，保持连接方式为 **公共 MQTT 中转**。

房主选择普通遭遇战或合作行动，点击 **创建房间**。成功后点击 **复制加密邀请口令**，把完整的 `RA1.` 开头长口令发给朋友。朋友将口令粘贴到同一页面，点击 **加入**。朋友准备后，由房主点击开始。

默认候选：`wss://broker.emqx.io:8084/mqtt`。另外提供用户指定的 EMQX 中国域名、HiveMQ，以及 Mosquitto 候选，可在界面修改。**候选不等于全部在线或已核验位于中国大陆。** 创建新房间连接失败可尝试下一个候选；已发出的邀请绑定原节点，不会暗中转入另一个房间。

公共 broker 只中转消息。实际对局运行在房主浏览器的独立 Worker 中。私密房间默认不在目录中发布，游戏消息使用按玩家分开的 ECDH / HKDF / AES-GCM 通道。公开房间会主动把加入邀请发布到当前节点目录。**房主需要保持页面和电脑运行，禁止休眠；关闭房主页面会结束房间。** 本版没有无缝主机迁移。

当前默认适合朋友间的休闲对战，建议从 2 至 4 人开始。协议支持最多 8 个参战席和 4 个观战席；8 客户端只做了本机协议验证，不代表公共免费 broker 能保证相同体验。详细说明见 [NETWORK_MQTT.md](docs/NETWORK_MQTT.md)。

## 同一局域网联机

房主运行 `START_LAN.bat`，保持控制台开启，按照启动页或邀请链接加入。朋友通过房主电脑的网页访问同一服务，无需在各自机器上安装 Node。

房主启动器优先使用本机 Node 22 及以上；没有时首次会尝试下载并校验官方 Windows 便携运行时。**本 ZIP 未内置 Windows Node 二进制，首次下载需要网络。** 已准备运行时后，局域网对局不使用公共 MQTT。

Linux/macOS 已有 Node 时运行 `./start-server.sh`，或 `node server/server.cjs --host 0.0.0.0 --port 8787`。不要把仅用于测试的 `tests/fixtures/mqtt-broker.cjs` 当作生产公网 broker。

## 常用操作

左键选择/框选，左键在地面下达命令，右键取消；**长按右键拖动镜头**。滚轮缩放。按住 `Z` 规划路径，松开提交；`Shift` 追加命令。`Ctrl+数字` 编队，数字选组，`A` 攻击移动，`S` 停止，`F1` 查看完整手册。操作详情以游戏内说明和 [CONTROLS.md](docs/CONTROLS.md) 为准。

## 推荐首次体验

先玩训练的“移动与路径”，然后尝试合作行动“漫长公路”。想与朋友对战时，再从私密双人房间开始。若卡顿，先设低画质、关闭阴影或减小显示分辨率；房主不要把运行中的页面放到长期后台。

单人存档属于当前浏览器、当前来源。移动文件夹、切换 file/localhost、换浏览器或隐私模式，可能读不到同一数据库。重要进度请导出 JSON。旧版存档可尝试兼容载入，但旧版录像不保证与新规则一致；跨版本联机明确拒绝。

## 项目结构

- `PLAY.html`：双击入口，和 `web/index.html` 内容一致。
- `web/src/`：完整可读源码。模拟、房间规则、MQTT、界面、模型相互分开。
- `server/`：原生 WebSocket 局域网/可自托管服务，依赖已随包。
- `tools/build.py`：生成两个自包含入口，计算真实共享源码内容标识。
- `tests/`：逻辑、协议、浏览器回归、压力基准和原始结果。
- `docs/`：使用说明、逐项交付矩阵、安全边界和实际截图。
- `deploy/`：可选自托管模板。本版公共 MQTT 功能不需要运行它。
- `SHA256SUMS.txt`：文件完整性清单，不是签名或来源认证。

开发者运行 `python tools/build.py`、`npm test`。浏览器测试需要 Python Playwright、Chromium 和可用的显示环境；Linux 无显示环境可使用 `xvfb-run -a npm run test:browser`。已有随包服务端依赖，不需要执行 `npm install`。

## 验证边界

本次在 Linux / Node 22 / Chromium / 软件 WebGL 环境进行测试。公共 MQTT 用独立的本机 MQTT 3.1.1 测试服务器验证真实协议、加密、8 客户端、恢复和延迟观战；没有用一个伪造成功状态代替连接。

**实际公共节点的可用性、中国跨运营商质量、Windows 首次下载、实体双机 LAN 和 RTX 4060 帧率没有实测。** 环境禁止导航到本地 URL，因此浏览器测试以完整 HTML 注入方式运行，IndexedDB/WebCrypto 在该不透明来源的受限提示有专门测试；加密端到端测试使用 Node 原生 WebSocket/WebCrypto 与真实房主 Worker 源码。

这是本项目的 **1.0.0 完整源码与运行包**，不是所有原版内容、美术、数值和商业在线运营条件均完成的承诺。请查看 [TEST_REPORT.md](docs/TEST_REPORT.md)、[UPGRADE_ACCEPTANCE.md](docs/UPGRADE_ACCEPTANCE.md) 和 [SECURITY.md](docs/SECURITY.md)。
