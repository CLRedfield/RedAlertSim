# 从0.6.0到1.0.0

v0.8功能和v1.0整合在同一交付内，没有要求玩家先安装0.8的更新链。

## v0.8内容阶段

实现6个合作任务及目标判定、任务状态快照、阶段增援、单人队友；只读观战席、30秒延迟、视角缓存；Replay v2检查点、最近检查点跳转；4个手动存档槽、2个自动槽、科技路线与行动记录。

## v1.0整合阶段

加入用户给定的公共MQTT节点列表与新建房间回退策略。实现原生MQTT3.1.1客户端、每位访客独立加密、长邀请口令、显式公开目录、节点握手诊断和房主退出通知。提取RoomService，使LAN与浏览器Worker共享实际房间与模拟代码。

补齐访客重连、房主掉线暂停/恢复、只读观战权限与动态菜单状态。修复无快照时打开观战菜单、近景细节/远景简化、旧界面入口遗漏新流程、两分钟AI接管重复提示、公共节点切换后界面地址不一致等边界。

新增116个实体定义的程序化细节层。工业设施的通风口、接缝、警戒标记、登高构件；重型载具装甲和后部组件；特殊武器机构、步兵装备、飞机与舰船局部细节。低画质与远景不提交这些细节网格，保留基础轮廓。

友军电脑保留正常生产与维护，在合作任务里按简报执行护送、油井、营救、攻坚和防守。寻路出现持续停滞时会清除过期路径并重新搜索，不传送单位。

## 保留并回归

右键长按拖图、短按取消/下令分流、Z路径、Shift追加、编队、建造快捷键、双生产类别、按格放置、碾压、三种迷雾、乘员操作、IFV/充能/磁电/炸弹/航空/奴隶机制，以及旧训练、沙盒和LAN功能。

本版没有把原版全部例外机制、商业美术、真实多层地形/桥梁、长期运营公网服务或跨运营商验收宣称完成。项目范围和原报告逐项对照在UPGRADE_ACCEPTANCE.md。
