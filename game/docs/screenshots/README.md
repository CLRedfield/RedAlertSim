# 1.0实际运行截图

100_home：指挥中心；100_operations：六任务；100_network：MQTT大厅；100_skirmish：部署；100_battle：战场；100_tech_tree：科技树；100_escort：护送任务；100_compact_network：960像素联机页面。

01到16由随包回归脚本重新生成，涵盖菜单、沙盒、放置、路径、键位、镜头、训练、回放、LAN房间与结算。具体脚本完成状态以tests/RELEASE_SUMMARY.json为准。

使用Xvfb和软件WebGL，不是RTX4060帧率证据。部分战斗场景由固定存档夹具建立，后续输入、模拟与绘制真实执行。公开MQTT在此环境只做独立本机协议测试，不把LAN房间截图当公网联机证据。
