# 公共 MQTT 联机使用与实现说明 · 1.0.0

## 最少操作路径

双方解压同一版本，打开 PLAY.html。房主进入联机大厅，以“公共 MQTT 中转”创建房间，复制完整 RA1. 邀请。朋友粘贴、加入、准备，房主开始。这里不要求游戏账号、路由器映射、安装 Node 或自己部署服务器。

口令不是界面显示的六位内部房间码。它包含绑定节点、随机房间主题、加入秘密和房主公钥，不能删减，也不要转成大写。公开发送邀请意味着允许得到它的人尝试加入。加入者不需要手动改成和房主相同的 broker，口令会选择正确节点。

## 节点选择

| 候选地址 | 来源与状态 |
|---|---|
| `wss://broker.emqx.io:8084/mqtt` | 默认；EMQX 官方公开 MQTT 服务地址 |
| `wss://broker-cn.emqx.io:8084/mqtt` | 用户指定候选；本次未验证现时可用性、证书或实际服务器位置 |
| `wss://broker.hivemq.com:8884/mqtt` | 用户指定候选；本次未做真实连接验收；仅协议测试，不作为游戏运营后端承诺 |
| `wss://test.mosquitto.org:8081/mqtt` | Mosquitto 测试服务公布的 WSS 地址；测试服务不保证稳定性 |

代码入口为 `web/src/mqtt-room.js`。创建新房间时按选定节点、其余候选顺序尝试，单次握手限时7秒。所有候选失败时会显示错误，不生成假房间。加入已存在的邀请只连接该邀请的节点。服务中途不可用不执行跨 broker 自动迁房，避免朋友被拆入不同对局。

“检查连接”会做实际 MQTT CONNECT 与 SUBSCRIBE。成功只说明当前机器这次能和这个节点完成协议握手，不说明房主已在线，更不是国内所有运营商或八人长局质量证明。

## 公共目录与私密邀请

默认勾选私密房间，不发布目录条目。取消勾选后，房主会把昵称、地图、人数、进行中状态和**完整加入邀请**公布到当前 broker 的项目目录。目录不是统一账号系统，不提供身份认证，当前节点以外的房间不会出现。

公开目录每15秒更新，客户端45秒后丢弃过期项目。保留消息和 MQTT 遗嘱用于清理广告，不保留游戏战场状态。断电时不一定能立即删除目录，稍后会过期。

## 实际架构

```
玩家输入 -> 加密 MQTT 通道 -> 房主浏览器 Worker
                                     |
                        RoomService -> Sim -> 个人视野过滤
                                     |
玩家画面 <- 增量/全量状态 <- 加密 MQTT 通道
```

LAN 服务端也加载同一 `authority.js` / `sim.js` / `tactics.js` / `operations.js`。不存在一份仅供网络使用、和本地任务规则不同的简化模拟。

模拟10Hz，状态发送约4Hz，ACK 增量基线、超时全量重同步。每个访客有独立 ECDH 密钥，通过 HKDF 导出 AES-256-GCM 通道。邀请绑定房主公钥；消息额外验证主题与单调序号。较大状态可 gzip 压缩，分片有数量、容量和15秒过期边界。

加密并不隐藏连接 IP、主题、消息时间和流量大小，也不阻止恶意节点拒绝转发。房主知道完整战场，可以修改自己的游戏程序；这不是可信竞技专用服务器。

## 掉线与退出

访客断网时禁止下令，保留原席位和命令序号；两分钟窗口内会尝试恢复，随后接收新的完整基线。房主的 broker 连接断开时暂停该房主的模拟，重连后恢复原会话。访客单独断线不会暂停所有人的比赛。

正常点击离开会尽量发出“房主已退出”通知。直接关浏览器、断电或系统杀进程不保证能发送最后消息，其他玩家由心跳超时发现。浏览器只会尽力运行后台 Worker，操作系统睡眠/计时节流不受游戏完全控制。

**没有主机迁移。** LAN 房间可能转交的是房间管理权限，Node 模拟仍由原主机承担；公共 MQTT 的模拟主机不能被其他浏览器无缝接替。

## 观战

从邀请或目录进入“延迟观战”，不占参战席，最多4位。观战看单个玩家的已过滤视角，不提供全图实时战场。开始后需要积累30模拟秒缓冲；选择尚未缓存的新视角也需要等待。结束后的结果可以立即显示，因为比赛已经结束。

观战者不能下令、改配置、准备、给参战玩家发聊天或标记。第三方语音软件不受本程序控制。

## 网络排障

“节点连接失败”：更换候选、确认本地网络允许 WSS 与对应端口，再重新创建房间。默认域名的文字中有 EMQX，不代表一定能从中国所有网络到达。

“房主未响应”：确认房主尚未退出、版本一致、口令完整、房主窗口没有被休眠。不要把内部六位房间码当作公共邀请。

“加密功能不可用”：使用常规现代桌面 Chrome/Edge，通过本地文件、localhost 或 HTTPS 打开。某些受限容器、嵌入浏览器和不安全 HTTP 来源不提供 WebCrypto。不要在普通远程 HTTP 页面加载公网模式。

“版本/哈希不匹配”：双方重新解压同一份完整发布包。仅把 VERSION 改成1.0不会解决实际内容不一致。

公共 broker 是共享测试基础设施，本包接入用于个人原型和协议验证，不代表获准以公共测试服务长期运营游戏。HiveMQ官方公共服务说明明确限制其用途，不应用作生产、开发、预发布或UAT环境。EMQX也将公开节点定位为原型/学习/测试，而不是生产保证。不要进行刷主题、大规模压测或大量公开房间滥用。真正公开长期运营仍需要可授权、可监控、容量可控的自有服务。
