# 1.0 已知差异与限制

## 本项目1.0不等于原版全量复刻

保留10国家、3大阵营、129实体定义，包括中立、系统生成及沙盒对象。成本、护甲倍率、弹道、特殊能力和所有组合尚未逐项与原作核定。目录存在不代表每项等价还原；详见CONTENT_STATUS.json。

九个旧样板加116个独立程序化细节层，并配合画质/距离LOD。没有完整PBR纹理库、原版图标、语音或音乐。模型是原创风格化几何，不是高精度商业资产。

六张地图有不同资源、道路与中立物，但没有完整高低地、可破坏桥梁或全面海陆地形编辑。等价主矿不等于所有采矿路径、人数与阵容已比赛级平衡。

## 任务和AI

六合作任务有目标、失败、时限和星级，可单人配友军AI或两人配合；这是独立短行动，不是原版战役。任务胜负夹具与存档/回放已测，但没有完整人工难度与长局平衡统计。友军会跟随护送、占点、攻坚与救援，仍为规则型AI。敌人波次是任务机制，不是正常经济作弊。普通/简单遭遇战不额外补经济，困难奖励明确披露。

## 联机

公共MQTT客户端已实现，第三方broker只转发，主机浏览器模拟。未实际部署中国专用游戏服务；不能确认所填broker-cn名称仍对应中国节点；没有真实公共连接或跨运营商验收。公开测试broker不是长期运营承诺。房主必须保持页面与电脑运行，没有主机无缝迁移；主机网络断开暂停、短时恢复后继续，主动关闭结束房间。

私密邀请默认不发布；公开房间会发布邀请。逐客人加密不等于第三方安全审计，也不阻止主机修改规则。LAN沿用ws8.17.1，不宣称最新或安全审计通过；正式部署前需核查依赖、代理IP链和容量。无LAN广播发现，多网卡可能需要选择可达地址。

## 存档、录像和环境

四手动/两自动槽依赖IndexedDB和稳定浏览器来源；可导出JSON避免来源变化丢失。回放基于相同内容哈希，旧版本录像不保证可用。300tick延迟观战可切视角但新视角可能重新等待；没有直播平台推流。v2录像检查点有内存预算，超长记录仍有大小限制。

此环境禁止file与localhost页面导航，浏览器通过in-memory HTML运行真实Worker/WebGL。其opaque来源不能持久化IndexedDB或使用WebCrypto，所以只验收失败提示和真实文件导出；加密联机独立由Node原生WebSocket/WebCrypto与实际主机Worker代码验证。实体Windows首次下载/防火墙、双机LAN、跨运营商公网、真实GPU帧率和跨浏览器重启存储均未实机确认。
