# 安全和运行边界 · 1.0.0

本说明描述实际防护及剩余风险，不是第三方安全审计报告。

## 公共中转

使用按访客独立的 ECDH P-256 / HKDF-SHA256 / AES-256-GCM 通道。邀请绑定房主公钥和随机加入秘密。消息包含独立随机 IV、单调序号、主题与压缩标志作为认证附加数据。篡改、主题替换和重复旧消息被拒绝。私密目录默认关闭。

发出公开邀请意味着允许持有邀请的人尝试加入。没有账户实名、陌生人信誉、防小号或反社工系统。加密不能保护你免受恶意房主作弊，也不能保证 broker 的可用性。不要在公开房间输入敏感信息。项目不记录游戏内聊天正文用于统计，也没有统计上报服务。

协议解析使用容量边界，分片组有数量与过期上限。解压输出、订阅等待、QoS1 待确认数量和发送积压均受限制。服务共享层还校验16KB单条客户端指令、命令频率、所有权、有限坐标、席位、版本、恢复令牌和序号。观战权限在模拟主机上检查，不仅仅隐藏按钮。

这些限制降低资源消耗和误用风险，但没有完成专业模糊测试、侧信道审查、互联网 DDoS 和极端慢客户端验证。

## LAN / 专用服务

沿用随包 WebSocket 实现 `ws 8.17.1`。它不是本次更新到最新的依赖，也不代表已确认不存在已知漏洞。默认 LAN 用途和可选公网部署用途需要区分。生产公开部署前必须重新审查依赖、反向代理信任链、认证和容量。

Node 服务端不把完整战场直接广播给每个玩家，先按视野筛选再做增量。恢复令牌为随机值，重连同样校验实际内容标识。完整比赛录像只在胜负确定后开放。

MQTT 主机与专用服务使用相同规则，但信任模型不同：浏览器房主由其中一位玩家控制，能看所有信息；专用服务的所有者也有完全管理权。

## 本地文件

文件存档/录像有版本、类型、大小、对象字段和实体范围检查。校验不是任意 JSON 都可执行的脚本解释器。Replay v2 检查点检查 tick/index 时间线一致性，旧规则录像不会靠改名被视为兼容。

本地 IndexedDB 可能被清理、被隐私模式隔离，或者因为来源不同而分开。重要进度请导出，不应把自动存档视为持久备份系统。

SHA256SUMS.txt 用于确认解压文件内容，清单本身没有数字签名，不提供发布者身份认证。

## 退出和可靠性

访客短断线支持保留两分钟；房主 relay 中断时暂停模拟。无缝主机迁移未实现，浏览器崩溃、断电、网页刷新均可能终止本房间。正常退出通知属于尽力发送，异常退出由超时发现。

公共 broker 由第三方运营。本包没有购买或部署中国大陆节点，也没有服务期限、负载、延迟或地域可达性的保证。测试记录详见 TEST_REPORT.md。
