# 1.0之后的真实验收清单

本版新增内容已交付，以下不是隐藏的“下次再实现”按钮，而是尚未获得的环境/完整性证据。

1. 用两台实体Windows测试本地打开、局域网启动、首次Node下载与防火墙；不同浏览器测试IndexedDB保存、重启恢复及JSON导入。
2. 在用户实际网络上测试默认EMQX与候选节点，记录握手、延迟、失连率与完整对局。若计划长期公开运营，接入允许该用途且有运维责任的服务，不将公共测试broker作为生产承诺。
3. 做2/4/8台真实客户端、不同运营商和慢连接的长局；测CPU、网络字节和RTX4060真实帧率。当前软件WebGL截图/合成模拟基准不能替代。
4. 继续逐单位原版数值/机制对照，特别是海军、载具、隐身、控制和航空复杂组合；扩展地图高低地、桥梁、海陆路线与平衡试玩。
5. 对加密握手/消息权限、ws依赖、存档解析进行外部审查；主机迁移、持久化、账号云存储和比赛级反作弊仍是独立工程。
