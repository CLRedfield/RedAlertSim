# 0.6.0 变更记录

本次基线为上传的 Web UX 0.4.0。0.5/0.6 的部分报告任务合并实现，不代表跳过了全部后续验收。

## 修复

对角出生、同型同量等距主矿、关闭席位、敌对关系校验、颜色/出生点冲突校验；投降引起的胜负变化即使模拟 tick 不再增加也强制推送结算；断线期间锁定命令；恢复凭据必须是有效的随机 48 位十六进制串，不能使用离开后被清空的 token；加载存档采用字段白名单，拒绝原型字段与恶意替换模拟方法。

## 新增

六图资源/中立物布局、自动团队出生分配、逐席位编辑、房间目录与私密房间、聊天/队伍消息/标记、真实断线重连、内容与共享源码哈希、每玩家视野安全的 ACK 增量。

五训练目标、六波挑战、记录和导入导出录像、进度定位、回放视角、结算统计/资金曲线、换边再战、军械属性详情、单乘员卸载、新的主菜单页面体系。

奴隶采矿实体，IFV 模式，线圈充能，磁电抬升，伊万倒计时，停机位分配与补弹。AI 侦察/情报记忆/防守/科技/扩张尝试，困难奖励显式说明。

九代表模型的程序化细节、步行动画、后坐、烟尘、队伍色条与道路视觉。Windows 启动器/Node 官方下载校验，服务启动无需 npm 安装。

## 未包含

实际公网服务；真正内置 Windows Node；原版全内容逐项对齐；复杂地形/桥梁；完整海军 AI；实时旁观；全面高模 PBR/LOD；真实跨运营商压力测试；服务器进程重启后恢复房间。
