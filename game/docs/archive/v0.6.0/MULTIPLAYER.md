# 联机使用与协议边界 · 0.6.0

## 玩家流程

房主完整解压并启动 START_LAN.bat；Windows 首次可能需要从官方站点下载 Node 便携运行时。启动后浏览器打开同源客户端；朋友只要使用同一局域网可达的邀请链接加入。主机控制台必须保持运行。详情与排错见根 README。

大厅 → 设置地图/人数 → 创建房间 → 发邀请 → 朋友加入并准备 → 开始。公开房间显示在当前服务器目录；私密房间不在目录，房间码本身不是加密密码。队伍、颜色、出生点在房间开始前校验。房主改动配置会重置准备。合作需要至少一个敌方 AI 席位，所有有效席位都在人类同一队时不允许开始。

复制邀请链接时，程序尝试将 localhost 换成服务端报告的 LAN 地址；多个网卡时请根据诊断结果使用可达地址。没有设置局域网广播发现或路由器自动映射。

## 临时断线

断线时客户端显示恢复状态，暂停提交指令，使用随机会话凭据自动重连。服务端保留原席位和指令序号两分钟，重连后先推送该玩家允许看到的全量状态。重连采用逐步延迟，不会无限快速重试。主动退出房间不应被当作临时断网；服务器关闭或重启不支持恢复。全员断线时对局等待，仍有玩家在线时继续。

## 技术

协议版本 4；客户端检查共享模拟源码/规则/地图内容哈希。100ms 固定逻辑步进，服务端权威执行命令。快照先按玩家可见性过滤，再构造 ACK 增量；未确认或失配时补全量，定期全量。仅在传输副本上量化视觉字段，不量化权威模拟。

开始对局前有身份、主机权限和配置检查；开始后有对象归属、最大指令数量、坐标、消息体积与频率检查。WebSocket 采用随包的 ws 8.17.1，不使用原包手写帧解析器。公开部署前需要更新/审计依赖，不能把随包版本视为已完成安全审计。

默认上限：16 房间、128 连接、单来源 20 连接、同来源最多 4 个未清理房间；16KB 消息；2MB 出站积压关闭慢客户端；未开局房间 15 分钟，对局 2 小时，上述 TTL 到期会结束房间。上限是保护阈值，不是同等规模性能验收结果。配置服务进程内存不会持久化到磁盘。

## 公网

本包没有实际在线的国内服务器。web/online.json 保持空，页面显示“未配置”。部署包和 configure-online 工具仅供运营方在获取真实服务资源后使用。玩家无需做部署，但这项交付依赖当前尚未具备的在线基础设施。禁止把其他服务的地址当成兼容的项目服务器。

## 排错

- 连接拒绝：检查主机控制台、端口和 IP，确认不是只启动了 PLAY.html。
- 超时：排查访客 Wi-Fi 隔离、不同子网、防火墙或 VPN 网卡；不要关闭全部系统防护。
- 版本不匹配：所有人使用同一完整包，开发者修改共享源码后重新运行 build.py。
- 不能开始：看房间提示，检查准备、敌方队伍、颜色/出生点冲突。
- 没有目录：目录只列当前服务器里尚未开始的公开房间，不是跨服务器全球匹配。

联机测试只验证了本机进程和浏览器客户之间的真实协议。实体双机 LAN 和中国跨运营商测试仍需现场验收。
