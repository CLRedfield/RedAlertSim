# Command Edition 架构

## 共享模拟

`data.js` 管内容、席位、地图与哈希；`sim.js` 管权威实体、战斗、队列、迷雾、存档；`tactics.js` 扩展独立阵营机制、训练、挑战、规则 AI、录像记录与重放。浏览器单人放在 Blob Web Worker 里，服务端用同一份模块；没有两套不同战斗规则。

`tools/build.py` 将 HTML/CSS/源码内联进两个相同入口。构建身份来自规范化 data.js + sim.js + tactics.js + wire.js 的 SHA-256，随后规则/地图内容形成连接检查。修改共享源码后必须重建。渲染/UI 文件单独由发布 SHA256SUMS 校验，不能在多人之间混用不同发布包。

## 渲染与输入

`geometry.js` / `art.js` 生成网格；`renderer.js` 管 WebGL2、地图、动画和覆盖层；`camera.js` 专门管理手势、缩放与输入安全。渲染只读快照，不执行战斗判定。`app.js` 保留生产/战斗输入和 Worker 桥接，`headquarters.js` 加入页面、房间、目标、录像/结算等流程，`command.css` 为新页面样式。

## 网络

`server/server.cjs` 管 HTTP 静态文件、房间、会话、验证与固定步进。`server/vendor/ws.cjs` 为 ws 8.17.1 固定构建。`net.js` 管客户端状态、恢复和 ACK；`wire.js` 管视野过滤后快照的量化副本与增量应用。完整权威状态不广播给客户端。

## 存档 / 录像

存档加载先校验树规模、字段类型、对象 ID、坐标、数量、队列与雾图，再按白名单导入。拒绝 __proto__/constructor 等危险键，不能用导入对象覆盖模拟方法。兼容部分 0.3/0.4 存档字段但不保证行为完全不变。

录像包含初始存档、共享内容版本、已接受的玩家命令和结束 tick；AI 按相同随机种子与固定步进重算，不重复记录 AI 指令。内部行动不成为玩家指令。回放必须内容哈希一致。联机完整录像只在结束后开放，防止战斗中导出全图情报。

## 已知工程边界

无数据库、匹配调度、集群房间路由、持久化或实时旁观。旧原型 app/sim 仍较大，未完成完整组件化/状态机重构。进一步拆分应保留现有操作回归与录像确定性测试，而不是一次性重写全部输入。
