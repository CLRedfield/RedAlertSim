# Red Alert 3D · Command Edition 0.6.0

基于你提供的 **Web UX 0.4.0** 直接升级的完整源码与可玩包。不是补丁，需要完整解压，不要覆盖旧包后混用文件。

## 先说明交付边界

**单人、训练、沙盒可离线运行；已实现局域网服务、真实房间协议、聊天、视野过滤同步、自动重连与录像。没有部署中国大陆公共服务器。** 游戏中的“公网服务未配置”是真实状态，`web/online.json` 没有伪造节点。`deploy/` 是未执行部署的运维配置，不是已经上线的服务。

**Windows Node 运行环境未内置。** 局域网启动器会优先使用本机 Node 22 或更高版本；没有时，从官方站点下载固定版本的便携运行时并校验 SHA-256。不需要 npm install。首次下载需要联网，可能受网络环境影响；Windows 下载、系统权限提示未在实体 Windows 上验收。

这不是原版引擎或已完整还原的《尤里的复仇》。本次完成范围与剩余项逐条列于 `docs/UPGRADE_ACCEPTANCE.md`，不要把 129 个定义理解成 129 个完全还原的单位。

## 立即开始

### 单人 / 沙盒 / 训练

1. 完整解压本包，双击 `PLAY.html`，或在 Windows 双击 `START_SINGLE_PLAYER.bat`。
2. 使用桌面浏览器并启用 WebGL 2。主菜单进入“遭遇战”“训练与挑战”或“战术试验场”。
3. 首次游玩建议先做“第一条命令”训练，再打双人普通电脑。设置中可切换经典左键下令与现代右键下令。

`START_DESKTOP.bat` 尝试用已安装的 Edge/Chrome 应用窗口打开本地网页，不是 Electron 原生客户端，也不是独立 Windows 游戏 EXE。浏览器若禁止本地 Worker 或 WebGL，可通过局域网启动器用 HTTP 打开，不需要联网对战。

### 局域网，房主 Windows

1. 房主双击 `START_LAN.bat`，保持控制台窗口开启。首次可能下载运行时。脚本不安装 npm、不修改 PATH、不要求管理员权限。
2. 浏览器自动打开，进入“联机大厅”，填写昵称，选择地图和人数，点击“创建房间”。
3. 点击“复制邀请链接”，发给同一网络里的朋友。朋友打开链接后加入房间，不需要自行安装 Node 或本游戏源码。
4. 房主可以逐席位设置国家、队伍、颜色、出生点、电脑难度或关闭席位。客人点击准备后，房主开始。

首次防火墙询问时仅允许自己信任的专用网络。不要关闭整个防火墙。访客 Wi-Fi 隔离、多个网卡或不同子网仍可能阻止连接；诊断页显示本机局域网地址，优先使用与你朋友在同一子网的地址。没有实现广播式自动发现或跨路由自动穿透。

### macOS / Linux 或已有 Node 的机器

```sh
./start-server.sh
# 或
node server/server.cjs --host 0.0.0.0 --port 8787 --open
```

单独执行 `node server/server.cjs` 默认仅监听本机 127.0.0.1。Windows 启动器会在 8787 到 8797 选择可用端口；其他启动方式可用 `--port` 指定。保持服务进程开启。

## 本版新增与修复

### 公平开局与地图

双人自动出生点对角分配；2/4/6/8 席位独立分配，自动位置按队伍分组，指定位置优先。八个候选位置各有两块同类型、同容量、同相对距离的主矿。关闭席位不生成基地，也不参与胜负判定。没有敌人的普通房间、重复颜色或重复指定出生点在开局前被拦截。

六个地图拥有不同的资源、中立建筑和道路视觉布局：双线矿谷、工业交叉口、海岸前线、四角荒原、双堡垒、开放盆地。它们不是六张原版地图复刻，也尚未包含复杂高低地、可破坏桥梁或所有陆海路径特例。

### 界面与操作

新的指挥中心，独立的遭遇战、训练、联机、军械资料库、录像与设置入口。部署页有实际出生点/资源预览、地图卡片和逐席位编辑。军械库可点开查看成本、属性、生产前置和当前实现说明。战斗中增加分类型选择、乘员单独卸载、事件记录、队友标记、聊天、连接状态和训练目标。结算增加统计、资金曲线、换边再战与录像导出。

保留右键长按拖图、短按取消/下令、Z 路径规划、Shift 追加命令、编队、生产快捷键、建筑方格、碾压和三种迷雾。详情见 `docs/CONTROLS.md`。并非完全替换所有旧面板，暂停/建造系统沿用并整合原有实现。

### 玩法与阵营机制

新增五个由真实游戏状态判定的训练目标，以及六波守卫挑战。补充尤里独立奴隶采矿、IFV 乘员武器切换和工程师维修、磁暴步兵充能线圈、磁电牵引、伊万延迟炸弹、飞机停机位/补弹/等待逻辑。AI 会侦察、依据视野与记忆选择战略目标、发展经济科技、尝试维修撤退与扩张；困难难度有明确披露的额外收入。

上述是本项目的玩法实现，不代表原版逐帧、数值或所有交互的等价实现。奴隶与运输等边缘组合仍需要更长时间试玩。完整目录与完成度见 `docs/CONTENT_STATUS.md` / `.json`。

### 视觉

为三系基础坦克、建造场与基础步兵共九个代表对象增强程序化造型细节，减少玩家颜色整片覆盖。加入步兵行走、炮塔后坐、移动尘土、受损烟雾、磁电抬升等可读性反馈。仍为风格化程序模型，不是九套完整高模/PBR/LOD 资产；没有引入原版贴图、音乐、语音或额外字体文件。

### 联机与录像

服务端权威模拟；客户端只发送命令。公开/私密房间、准备、聊天、队伍消息、标记、内容哈希检查、ACK 增量同步、补全量、两分钟席位恢复与重连输入锁。每位玩家先按迷雾过滤再计算增量，不把全图敌人状态放进客户端。联机不允许沙盒命令，完整录像仅对局结束后开放。

本地录像支持导出/导入、暂停、0.5–3 倍速、时间定位、玩家视角切换；同内容版本的命令回放已做确定性测试。最近 3 份小录像可尝试缓存在浏览器，但重要录像应保存成文件。主动“离开”不是断线恢复，服务器重启也不保留房间。实时旁观席、跨版本录像和服务器持久化恢复未实现。

## 公网接入现在到哪一步

客户端、服务端和配置接口已提供，但**本包没有实际在线的中国公共节点，没有域名、服务器资源或运营凭据**。点击公网入口会如实说明未配置，不会偷偷连到其他服务。未来必须由运营方实际部署兼容服务、配置域名/HTTPS/WSS、处理适用手续并进行真实跨运营商测试。玩家端不应该承担这些运维工作。

`deploy/README.md` 面向未来维护者，包含未执行的容器/反向代理模板和检查清单。不要把它当成玩家必做步骤，更不要把模板当成公网验收完成。

## 测试与限制

本包包含可重跑的 Node 测试、实际浏览器鼠标/键盘/Worker 测试及截图。**准确数量和完成状态以 `tests/RELEASE_SUMMARY.json` 与 `docs/TEST_REPORT.md` 为准。** 八客户端协议测试是在同一 Linux 主机上创建虚拟客户端，不是八台实体电脑或中国跨运营商测试。浏览器使用 Xvfb 和软件 WebGL，不代表 RTX 4060 的帧率。Windows 启动器、直接 file URL 导航、跨浏览器重启存储和实际公网部署未在此环境验收。

## 开发与目录

```sh
python tools/build.py
npm test
# 浏览器回归需要本机 Python Playwright、Chromium 和图形显示环境
xvfb-run -a python tests/browser_smoke.py
```

生成 `PLAY.html` 与 `web/index.html` 时自动更新共享模拟源码哈希。修改共享源码后必须重新构建并同时更新所有客户端/服务器，不能只替换一方。

- `PLAY.html`：完整离线客户端，全部运行时美术/音效由本地代码生成。
- `web/src/`：界面、模拟、网络、相机与渲染源码；`web/online.json`：空公网配置。
- `server/`：权威服务器与随包 vendored `ws`，无需在线 npm 安装。
- `tools/`：构建、Windows 首次引导、实际节点配置工具。
- `runtime/`：运行时说明及首次下载缓存位置，不含已下载的 Node 二进制。
- `tests/`：测试源码和本次结果；`docs/screenshots/`：实机浏览器截图。
- `docs/`：升级验收、控制说明、已知差异、第三方来源；`docs/archive/`：旧版参考，非本版测试结果。
- `deploy/`：尚未执行的运维模板。`SHA256SUMS.txt`：发布文件校验。
