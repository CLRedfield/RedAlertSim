# 本版已知差异与边界

## 与原作的差异

目录包含 10 个国家、3 个大阵营和 129 个实体定义，其中有中立、沙盒和系统生成对象。它不是 129 个都能正常生产且原版等价的单位。成本、弹道、护甲倍率、升级及特殊交互都没有完成与原版 1.001 的逐项验证。

三维模型由代码生成，基本图标仍有共享风格。九个代表样板只是细节增强，未实现完整高模/贴图/LOD 管线。语音和音乐不是原版音频。

奴隶矿工、IFV、磁暴充能、磁电、伊万和航空补弹有独立逻辑，但具体时间、伤害、回收/失控和复杂运输交互是本工程近似实现，不承诺原版全部例外。其他单位有原包遗留的近似能力，见目录完成度表。

## 地图与 AI

六张地图的资源/建筑布局不同；四边海域、道路和驻军建筑可形成一定差异，但没有真正的高低地系统、桥梁破坏/修复、完整水陆连接工具。矿区等价指起始两块矿的类型、容量和相对距离，不等于所有地图、所有人数、所有海军路线已达到比赛级平衡。

自动出生优先按队伍分组，手动指定可覆盖这一行为。4v4 预设在小规模人数下解释为人数等分的两队，不会把四人局全部放入同队。

AI 的战略目标基于侦察和记忆，初始出生席位属于公开房间信息。它仍然是规则型 AI，不是完整原版电脑。常规模拟的自动瞄准/弹道中还存在既有近似逻辑。普通/简单没有新增额外经济奖励；困难有显式收入奖励。海军战术、持续编队和复杂撤退/维修组合还需要继续扩展。

## 网络与交付

公网未部署。没有真实局域网广播发现，邀请链接仍依赖可达的局域网 IP。多网卡时自动挑选的地址可能不是朋友所在子网，诊断页显示候选地址。宿舍/访客网络隔离需要网络管理员处理，不能靠游戏绕过。

服务器权威不等于专业反作弊认证。已做消息大小、频率、归属、版本和视野过滤等测试，但未做外部安全审计。所附 ws 为固定 8.17.1，不宣称最新、无漏洞或适合未经审查公开部署。反向代理下当前 IP 配额按代理连接源计算，可能共享 20 连接限制；部署前必须设计并审查可信真实 IP 链，而不能直接信任客户端 X-Forwarded-For。

服务器状态在内存中；进程重启不能恢复对局。主动离开会失去恢复资格；临时断线保留两分钟，期间剩余玩家继续对局，最后一人断线时模拟等待。没有实时旁观席或跨版本录像支持。超长录像定位可能短暂等待。

## 尚未实机验收

Windows 首次运行时下载/校验/执行、Windows 防火墙、实体双机 LAN、跨中国运营商公网、真实 GPU 帧率、直接 file URL 的浏览器策略，以及关闭重开浏览器后的存储。此环境采用 in-memory HTML、真实 Worker/WebGL 与真实本机 WebSocket 协议测试，详细记录见 TEST_REPORT.md。
