# 已知差异与未完成内容 · 0.4.0

这是交付范围说明，不是把未完成内容当作已经完成。目标规格仍是后续方向，当前包交付的是已经整合本轮操作增强的可玩工程，尚非最终全量原版重制。

## 原版兼容性

尚未导入或比对原版1.001规则文件。成本、生命、伤害、射程、装甲乘区、科技前置、生产时间、电力、视野和移动速度都属于本原型数据。使用10Hz固定步长，和原版速度档没有已验证映射。默认战备基地是方便试玩的快捷开局，不是原版常规开局；也提供基地车开局。

本轮已补齐碾压、路径点、快捷键、方格、三种迷雾、主工厂及生产反馈，具体见OPERATIONS_AUDIT.md。鼠标使用经典左键模式，但这些实现并未逐项通过原版引擎对照，部分键位和巡逻属于扩展。选择指令每次最多1024个实体，生产队列每类最多24项。没有设定全局人口上限，也没有完成大规模长期玩法平衡。

三张地图共享拓扑和出生点，主要是海岸 / 灰岩 / 荒原环境变体。没有原版地图格式导入、可破坏桥梁、坡道、高地层、桥下通行和地形高度影响。

## 美术 / 声音 / 界面

当前为原创程序化低多边形模型，多部件组合并非高精度原版模型重制。部分同类模型和生产图标复用造型。没有原版音乐、语音、电影片段、肖像或图标，也没有原版完整建造 / 死亡序列动画。

有战场、主菜单、设置、房间、手册、图鉴和结算，但还不是原版侧栏的像素级高清重绘。图鉴是图标与数值目录，不是自由旋转三维模型查看器。

## 联机 / 存档

同一模拟核心在Worker和服务器运行，使用服务器权威状态，不是全客户端确定性锁步。当前按10Hz发送经过视野过滤的完整快照，没有状态差量压缩。8真人、复杂延迟 / 抖动、长时间公网稳定性没有测试。

支持本机实测的真实WebSocket房间。协议有恢复凭证，但客户端没有自动重连 / 恢复交互。没有观战、聊天、回放播放器、录像分享、房间列表、账户、匹配、反作弊完整体系或对原版客户端的兼容。多人不支持游戏内保存和读档。

单机JSON存档保存实体、生产、矿区、随机与AI状态；瞬时特效不恢复。浏览器快速存储在部分本地文件 / 隐私模式可能被限制，导出JSON是另一入口。0.4.0接受0.3.0及0.4.0存档；0.2.0不兼容。新存档还包含命令队列、主生产厂、集结路线、独立就绪槽与迷雾模式。

## 0.4镜头体验的边界

右键拖图、持续滚屏、全屏和参数设置属于本工程体验扩展，不冒称原版默认规则。相机是本地视觉状态，网络不发送相机位置。改进输入手感并不等于提高所有场景帧率；未在RTX4060上测试，也没有原生引擎迁移。

START_DESKTOP.bat是调用本机Edge/Chrome应用窗口的Windows启动器，不是原生EXE、不包含浏览器运行时，不自动处理公网联机。本轮只做静态审查，没有Windows双击实测。浏览器策略拒绝全屏时回退提示；全屏由用户点击触发。

没有强制锁住鼠标或隐藏系统光标。抓取模式受屏幕边界限制，可选择持续滚屏来减少抬鼠标次数。指针捕获保证离开画布后仍能结束一次手势，但不是无限鼠标位移API。左键框选拖出战场时不自动滚屏，避免新手误滚；这是当前有意保留的输入取舍。多鼠标键同时按下会中止当前手势，不下达不确定指令。

本地偏好在浏览器允许localStorage时持久化；文件路径、浏览器配置或隐私模式变化后可能不是同一存储区。本轮容器禁止直接导航file://，浏览器测试使用完整HTML内存载入，没有实测跨刷新持久化。新页面会按实际存储可用情况显示提示。
