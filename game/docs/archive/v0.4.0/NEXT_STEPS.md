# 后续开发任务与验收顺序

0.4.0已加入右键拖图、镜头设置与独立窗口入口，见UX_CHANGELOG.md。0.3.0操作增强保留，见OPERATIONS_AUDIT.md。以下是仍未完成的全量目标，不与本轮改动重复标记。

## 第一优先：真实试玩反馈

在目标Windows电脑和RTX4060测试1440p / 1080p，记录CPU、内存、浏览器、帧耗时和实体数。邀请另一台真实电脑测试局域网。复现并修复堵路、生产出口、攻击移动、运输上下车、失去电力和跨阵营控制的异常。

完成8席位100 / 300 / 600实体的帧时间、模拟耗时、网络数据量测试。不得把当前软件WebGL截图的帧率写成用户电脑性能。

## 第二优先：原版内容及机制审计

使用合法持有的干净1.001规则文件和原版运行行为作对照。补一张“原版定义 → 本工程定义 → 缺失状态”的映射，去重阵营公共建筑和单位变体。

逐个核对科技树、价格、武器、装甲、技能、生产时序与胜负。未对照的字段保持“未验证”，不能批量改成“完成”。先解决奴隶实体、抹除、磁电抬升、航母舰载机、间谍偷科技、多功能车组合、原版投射物等最明显差异。

## 第三优先：美术达到目标标准

先做灰熊 / 犀牛 / 狂风、三阵营建造场和步兵的统一高质量模型样板，再引入glTF外部模型、骨骼动画、正确的炮塔绑定、材质和LOD。现有程序化网格保留为测试资源，而非最终精美建模标准。

将模板化图标替换为清晰的逐单位渲染图，侧栏按原版视觉逻辑细化，但不要改变规则层。

## 第四优先：联机可靠性

加入客户端可见的断线恢复、房间配置保存、队伍 / 出生点设置、观战、聊天。改为快照差量和合理插值队列，按不同网络条件验证指令响应。公共部署需要独立安全审查，不把私人原型直接当成熟公网服务。

## 第五优先：地图和完整交付

真实海岛 / 城市 / 桥梁地图，桥梁破坏与地形层级，完整中立设施，地图编辑 / 导入，稳定的回放机制。最后再进行全单位复杂交互回归、UI适配和长局压力测试。

沿用最初的方向：十势力、三体系、原版规则忠实、精细风格化三维、单机与联机同优先、8方；当前原型不是这些最终验收要求的全部完成。
