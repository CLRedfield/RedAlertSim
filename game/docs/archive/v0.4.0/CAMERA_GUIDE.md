# 镜头与手感使用说明 · 0.4.0

## 从这里开始

进入战场后，在主战场按住右键并移动鼠标。默认160毫秒进入长按状态；明显拖动超过6个CSS像素也会立即识别，不必每次先等。松手立即停止相机，不继续滑行。

短按仍执行原右键功能：经典模式为取消工具/选择，现代模式为给当前所选单位下令。为了区分拖图，短按动作在松手时执行，不再在按下瞬间执行。一次手势已经进入拖图后，松手不会再补发移动、攻击、取消或建造命令。长按不移动也不会误下令。

右键拖图只从主战场开始。生产栏和小地图保留自己的右键功能，不能从生产图标按下后期待它拖图；这避免把暂停生产、取消退款和小地图指令混在一起。中键立即拖图仍然可用。

## 两种拖图方式

**抓取地图，默认。** 拖向右边时地面随手向右移；按住并来回移动，地图与手的位移对应。适合微调视野、边建造边移动镜头。设置中的“反转抓取方向”可反过来，它同样作用于中键。

**持续滚屏。** 在顶部“镜头设置”中选择“持续滚屏”。右键按下的地方成为临时起点，向想看的方向偏移，镜头就持续往那边走。偏离越远滚动越快，不再继续移动鼠标也会滚屏；回到起点附近的死区停止，松手完全停止。适合远距离穿越地图，尤其是鼠标快到屏幕边缘时。

抓取灵敏度只调抓取位移；持续滚屏速度通过“滚屏速度”调节。不强制锁住系统光标，不使用无限鼠标位移，不需要额外权限。持续滚屏可以减少反复抬起鼠标的次数，但并未把它冒称为原生光标锁定。

## 设置入口和推荐

顶部“镜头设置”、暂停菜单“镜头与手感”、主菜单“镜头与手感”都可打开同一面板。单机局内打开会暂停；联机局内仅阻止自己的操作，不暂停服务器。返回时恢复打开前的暂停状态。

| 使用习惯 | 建议起点 | 之后调什么 |
| --- | --- | --- |
| 普通鼠标，近距离指挥 | “抓取拖图”预设 | 抓取灵敏度0.8至1.2，按习惯选择方向 |
| 8方大地图，需要经常转场 | “持续滚屏”预设 | 滚屏速度起点800 px/s，可降低到更容易停准的位置 |
| 笔记本触控板或滚动较敏感 | “触控板预设” | 边缘滚动关闭，缩放灵敏度0.65，长按200ms；还需要触控板本身能保持右键按下 |
| 只想用方向键和小地图 | 关闭长按右键拖图与边缘滚动 | 右键完全保留点按，方向键速度单独可调 |

这是本项目参数建议，不是针对某型号硬件的性能承诺。预设只改相关手感项，保留其他偏好；“恢复默认”才恢复全部镜头、控制、音量与画质偏好。

默认边缘宽度20 CSS像素，停留100ms后滚动，越接近边缘越快。支持关闭、调整边缘宽度与停留延迟、仅在游戏内全屏启用。底部界面不再覆盖可滚屏战场边缘，去生产栏操作时不会带动镜头。正在左键框选时不会叠加边缘滚动，这是本版的防误操作取舍。

“柔和起步”只平滑开始移动的速度，释放后立即停止，不制造惯性。逻辑按经过的时间计算而不是每渲染一帧固定移动；真实主线程长期卡顿仍需性能优化，不能只靠手感设置解决。

## 缩放与定位

滚轮默认围绕鼠标所指地面缩放，减少先缩放再找回目标的操作。地图边界限制下无法保证锚点绝对不动。可关闭鼠标锚定，改为屏幕中心缩放。

支持平滑缩放和缩放速度。处理像素、行、页三种WheelEvent单位；只在主战场拦截滚轮，生产列表照常滚动，不同时缩放地图。

| 键位/入口 | 功能 |
| --- | --- |
| Home | 把镜头移到当前所选单位的平均位置，不是持续跟随 |
| End | 恢复默认缩放，显示为100% |
| H / F2 | 保留原有选中并定位建造场 |
| 方向键 | 平移，斜向做归一化，不额外加速 |
| Shift+方向键 | 约1.75倍平移速度 |
| 空格 | 保留跳转最近警报位置 |
| 小地图左键拖动 | 雷达可用时快速定位 |
| 底部VIEW工具条 | 缩放加/减、100%复位、定位所选 |

Home/End和其他普通动作一样可在键位设置重绑定；按钮提示会显示当前绑定。位置定位会结束尚未完成的缩放动画，避免定位后镜头又跳回。

## 全屏与独立窗口

在游戏里点击“全屏”，或按Alt+Enter。再次操作退出。全屏失败时显示可用替代提示；不会请求管理员权限或修改浏览器策略。浏览器自己的F11与游戏的Fullscreen API不是同一状态，“仅在全屏边缘滚动”检查游戏内全屏，不能保证识别浏览器F11。

Windows可运行根目录 `START_DESKTOP.bat`。它在常见安装位置查找已安装的Edge/Chrome，通过应用窗口模式打开本地PLAY.html，尽量去掉地址栏和标签页。启动失败回退系统默认浏览器。

**这仍是网页程序的独立窗口，不是原生客户端或已编译EXE。** 不含浏览器运行时、不下载依赖、不关闭安全开关，也不能因为换了窗口就保证更高FPS。该Windows启动器未在Windows双击实测；浏览器全屏按钮已在测试环境中实际进入和退出。

联机仍使用原来的联机服务器与HTTP地址。桌面窗口启动器默认打开离线单机入口，不会替你开启房间服务器或穿透路由器。

## 设置、误触与恢复

镜头、控制预设、画质、音量和提示开关尝试保存在当前浏览器本地。不能存储时，面板会明确提示只在本次打开有效。浏览器配置、文件位置或隐私设置改变后，设置不一定在同一存储区；本次没有跨刷新/跨浏览器迁移测试。

失去窗口焦点、切换标签、Pointer取消/丢失捕获、打开弹窗或改变窗口大小都会安全释放手势。拖动结束于侧栏上时不会点击穿透。左右键同时按下会取消不确定手势，不猜测玩家想发什么命令。

拖图保留当前选兵、就绪建筑的放置模式和未提交的Z路径；短按右键仍可主动取消。切出窗口会取消未提交路径，沿用上一版规则，不会在重新切回来时偷偷提交。保存、载入和切换游戏也会清理输入状态。

联机镜头不发网络命令，不会改变其他玩家的视角，也不绕过迷雾。进入镜头设置不会把联机游戏暂停。
