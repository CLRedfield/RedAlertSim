# 操作完整性检查与本轮改动 · 0.3.0

审查基于0.2.0的现有源码与用户反馈；下面分别记录已实现内容和仍待完成的原版对照。功能存在、操作可用、与原版完全一致，是三种不同结论。

## 边界和下一步仍须注意的细节

建筑目前为统一尺度的矩形基础占地，并非逐个核对原版异形Foundation。本轮没有连续拖拽围墙、原版连接围墙逻辑、坡道、高低地层和可破坏桥梁。格子功能本身已实现，不等于原版地图逻辑全部完成。

路径点与寻路是两个系统：队列和路径规划已完成本轮实现，但狭路大量单位的让路、精细队形、运输集结规则仍需原版对照和长局测试。追加到永久巡逻后面的命令不会自动抢占巡逻。自动AI暂不专门规划碾压冲锋或复杂多点进攻。

生产仍使用原型预扣整单费用和每类最多24个订单，不是经过验证的原版逐帧扣款/多工厂加速规则。按类型整批下单仍受现有英雄等限制。出兵堵塞虽有检测，但不是完整人群避让系统。

隐身、裂缝、卫星等原型特殊能力保留已有简化实现。无迷雾不等于自动反隐；从全图切回双层保留已探索地形。移动敌军、静态建筑记忆、矿区记忆和隐藏命令已经分开处理。

尚未实现的全量原版特性包括真正的奴隶实体、完整间谍偷科技、多乘员精确IFV组合、超时空抹除协作、磁电真实抬升/落地伤害、舰载机实体、桥梁、更多战役中立单位等。请看KNOWN_DIFFERENCES.md，不把“操作增强完整包”误当“所有原版内容最终完成”。
