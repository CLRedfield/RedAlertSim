# 联机指南 · 1.0.0

## 公共MQTT中转

朋友双方完整解压同一1.0包，打开PLAY.html → 联机大厅 → 公共MQTT中转。房主创建房间，发送完整RA1.邀请口令；朋友粘贴口令并加入，准备后开始。朋友无需运行Node或配置路由器。创建前选合作行动可开双人任务。详细节点、隐私、诊断和恢复规则见NETWORK_MQTT.md。

邀请绑定具体节点，不能自行截成六码，也不能修改节点后沿用旧口令。公开目录只显示同一节点的公开房间，私密房间默认不发布。房主须保持页面开启、电脑不休眠；后台节流可能降低模拟速度。

## 局域网或专用服务

房主运行START_LAN.bat，浏览器中选择“局域网 / 专用服务器”。客人打开房主复制的同网可达链接。首次可能下载并校验Node；本包未内置Windows运行时。只双击PLAY.html不会启动LAN服务器。

两种连接方式共用协议5、固定100ms步进、准备/席位/权限、视野过滤ACK增量和两分钟恢复。LAN由Node服务执行模拟，因此浏览器房主离开不等同于服务进程关闭。公开MQTT则依赖主机Worker，主机退出会结束房间。

## 观战和录像

观察者独立占用最多四个只读位置，不占八个玩家席位。观看约30秒模拟时间前的快照；新视角没有缓存时要重新等待。观察者不能下令、改房间、发参战聊天或队友标记。结束后可导出完整录像；游戏中不能用导出来看全图。

## 安全和验收

LAN房间六码本身不是密码；随机会话token用于恢复。MQTT邀请包含房间密钥和主机公钥，应只发给可信参与者；公开房间会主动发布邀请。房主掌握完整状态，非可信反作弊服务器。公共测试节点不保证可用性、地域或长期运营；未做真实跨运营商测试。

默认Node保护边界为16房间、128连接、每来源20连接、16KB命令、2MB出站积压。浏览器主机只开一个房间；这些都是保护阈值，非压力验收承诺。反向代理下真实IP信任链与ws固定依赖需另行审查。

## 排错

连接失败先核对当前模式：MQTT使用wss节点和RA1.口令，LAN使用ws/wss游戏服务和六码。MQTT点击网络诊断可检查加密功能、节点握手和订阅。LAN检查房主控制台、防火墙专用网络权限、正确网卡与Wi-Fi隔离，不要关闭整个防火墙。HTTPS页面不能直接连接不安全的远端ws地址。
