# 默认键位与操作 · 1.0.0

下面是本包默认预设，不宣称每项都等于原版默认键。Esc中的“键位设置”可重绑定；表中的鼠标组合、编队数字、Esc/F1/Tab/空格等是保留操作。重绑定后看HUD或设置页面显示的新键。

## 部队指挥

经典模式下令用左键，现代模式下令用短按右键；长按右键拖图不会下令。选取始终使用左键；显式命令工具A/M等仍可用左键指定位置。

| Shift点单位 | 增减选择 |
| 双击单位 / T | 选择屏幕内同类；快速双按T扩展全图己方同类 |
| P | 选择屏幕内作战部队，不包括矿车和建筑 |
| Ctrl+0…9 | 保存编队 |
| 数字 / 双按数字 | 选编队 / 镜头定位编队 |
| Shift+数字 / Ctrl+Shift+数字 | 追加选择 / 把当前选择追加到编队 |
| A / M | 攻击移动 / 普通移动工具 |
| S | 停止，取消当前目标、路径、待执行命令 |

| X / G | 散开 / 原地驻守警戒，警戒不主动追出射程 |

## 路径点

按住Z，左键添加节点，松开Z发送整个计划。也可以点击底部路径按钮进入持续规划，Enter发送、Backspace撤回末点、Esc或右键取消。规划新路线本身不会发送任何移动指令，原来已经在执行的命令继续执行。

第一点同时按Shift可把整条计划追加到旧路线；普通Shift下令也可以逐条追加。每次计划最多64个节点，每个单位最多64个等待节点。等待中的攻击目标被摧毁或失去可见性时，不追踪其隐藏坐标，结束该目标命令后继续队列。巡逻、地面强制攻击等持续命令不会自动结束。

选中生产厂可用路径工具设置集结路线。为了控制画面拥挤，只绘制最多16个所选对象的常驻路线；这不是模拟/选择人数限制。临时规划显示一条代表路线。

双层：从未探索区为黑幕；离开视野后回笼，敌方移动单位不再可见，敌方建筑保留最后所见的静态记忆。

单层：探索过的区域持续可见，不会回笼；此为本包默认选项。

无迷雾：整个地图可见。以上三种模式仍保留隐身/反隐规则，并不自动关闭裂缝等简化特殊逻辑。没有雷达时小地图仍不可操作。

单机在暂停菜单切换；从“无迷雾”切回双层不会抹去已经探索过的地形记忆。联机由房主开局前选择并锁定，客户端不能自行改规则。

长按按键不会反复切换生产栏、建筑或模式。输入框、搜索框、房间码输入和中文输入法组合输入期间不发战斗快捷命令。窗口失焦取消尚未提交的规划并释放方向键状态，避免回来时自动乱跑。

## 右键与镜头的边界

主战场默认160ms长按或6 CSS像素拖动后切入镜头操作；仅长按不移动也会吞掉松手的指令。拖图保持当前选择、未放建筑、未提交路径。生产栏右键仍暂停/取消生产，小地图右键仍下令，不把所有右键点击都改成拖图。方向和抓取灵敏度只影响抓取模式；持续滚屏看起点偏移和滚屏速度。

边缘滚动有100ms默认停留延迟，宽度20 CSS像素，可关闭或只在游戏内全屏使用。底部HUD、侧栏和设置窗口不触发滚屏。Home定位的是当前所选单位的中心，不是持续跟随。切出窗口会取消尚未提交的路径规划，沿用0.3的输入安全约定。

详细场景和预设见CAMERA_GUIDE.md。


## Command Edition 界面

主菜单左栏切换遭遇战、训练、联机、资料库、录像与设置。遭遇战的“战术试验场”开启沙盒；联机禁止沙盒。联机大厅中的“准备”由客人操作，“开始”由房主操作。

战斗中的“事件”打开警报记录，点击条目可定位；“聊天”打开房间通讯，勾选“仅队友”限制接收方；“标记位置”进入地面标记工具。“保存录像”导出本地记录，联网时须等对局结束。运输工具的乘员条目可逐个卸载，不会授权控制其他玩家的运输工具。

录像通过“录像与存档”导入，不是普通存档加载。回放中暂停、速度、时间滑条和视角选择独立控制本地回放；不能向回放发出战斗命令。训练完成会显示下一项按钮，也可随时退出。

## 1.0任务、存档与观战

战斗左下“存档”打开4个手动槽和JSON导出，“科技”查看实际前置。单人每60秒尝试自动存档，联机和录像中不会写单人存档。

合作任务由目标HUD显示实时条件，任务的“退出行动”回到六任务选择页。护送补给车不接收直接移动命令，只有友军战斗单位在附近才会前进。

观察者顶部栏切换视角，不能操作战场；新视角可能重新等待30秒缓冲。
