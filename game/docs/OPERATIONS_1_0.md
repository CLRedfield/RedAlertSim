# 合作行动指南

六个行动都有独立目标、时限、失败条件、存档状态和结算。标准歼灭规则不会提前覆盖任务目标。单人有一位友军电脑，联网最多两名人类位于固定同一队，敌方由任务或电脑模拟。

| 行动 | 目标 | 失败条件 | 标准时间 |
|---|---|---|---|
| 钢铁守夜 | 消灭8波任务增援，最后一波敌军必须清空 | 双方基地体系全部失守或15分钟用尽 | 7分30秒 |
| 黑金争夺 | 同时控制至少2座任务油井，累计90秒；失去多数时计时暂停 | 12分钟用尽或全部友军基地失守 | 5分30秒 |
| 漫长公路 | 装甲补给车通过5个路标；20格内有友军地面战斗单位才继续 | 补给车被毁、14分钟用尽或基地失守 | 7分钟 |
| 静默频段 | 摧毁或占领3座指定雷达站 | 8分钟用尽或基地失守 | 5分30秒 |
| 心灵要塞 | 摧毁或占领中央心灵信标 | 15分钟用尽或基地失守 | 8分钟 |
| 归航信号 | 地面战斗单位靠近3处小队8格接应，再由至少2支地面战斗单位控制撤离区30秒 | 未接应的小队被毁、14分钟用尽或基地失守 | 7分钟 |

任务地图上的金色编号与边框表示简报里公开的任务位置，不是开启全图敌方视野。护送路线、营救位置、雷达位置属于事先已知情报。

## 友军电脑

保留正常建造、生产、维修和自身防御，不额外获得普通难度经济补贴。任务中会优先护送补给车、前往营救点、进攻标记设施、争夺油井或在基地前沿防守。工程师先接近尚未发现的油井，进入自身视野后才执行捕获指令，避免以未见目标 ID 绕过命令校验。

这是规则驱动队友，不保证每一次路线、编队与决策都是最优。合作任务还没有进行玩家长时间难度调校。两名玩家应主动分配经济、防守和目标分工。

## 评分与记录

完成目标得1星；不超过表中标准时间再得1星；两位盟友累计损失不超过25再得1星。成绩保存在本机浏览器，保存最高星数与最快完成时间。不接入账号或云端排行榜。

护送车不可被直接派遣或部署成建造场。它采用本任务指定路线；通过调度护卫部队决定停走。油井控制是累计时间，撤离区的控制也是累计有效秒数；受到敌军争夺时暂停而非归零。

任务进度写入单人存档，录像的初始状态和检查点也保存目标状态。联机进行中不开放其他玩家的完整存档或录像，结束后才提供录像导出。大型在线录像会先减少优化检查点，保留指令时间线；超过在线体积上限则显示失败，不提供半份文件。
